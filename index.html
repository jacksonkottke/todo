    Connect to GitHub

    This app reads and saves your lists in the private briefings repo, the same files your new-tab page and Claude use. Paste a GitHub token that can read and write that repo. It's kept only on this phone.

    Make a token on GitHub: name it anything, Repository access → Only select repositories → briefings, then Permissions → Contents: Read and write.
